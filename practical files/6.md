# Practical 6 — String Validation using Recursive Descent Parsing (RDP)

## Objective

Implement a Recursive Descent Parser (RDP) to validate an input string against the following grammar:

```
S  → ( L ) | a
L  → S L'
L' → , S L' | ε
```

---

## Grammar Analysis

| Non-Terminal | Production Rule | Meaning |
|---|---|---|
| S | `( L )` or `a` | A single atom `a` or a parenthesized list |
| L | `S L'` | At least one S, possibly followed by more |
| L' | `, S L'` or `ε` | Zero or more comma-separated continuations |

**First Sets:**
- FIRST(S) = `{(, a}`
- FIRST(L) = `{(, a}`
- FIRST(L') = `{,, ε}`

This grammar is **LL(1)** — no ambiguity, suitable for recursive descent.

## C Implementation

```c
#include <stdio.h>
#include <string.h>
#include <stdlib.h>

// Grammar:
// S  -> ( L ) | a
// L  -> S L'
// L' -> , S L' | epsilon

const char *input;
int pos;
int error;

void parse_S();
void parse_L();
void parse_Lprime();

char current() {
    return input[pos];
}

void consume(char expected) {
    if (input[pos] == expected) {
        pos++;
    } else {
        error = 1;
    }
}

// S -> ( L ) | a
void parse_S() {
    if (error) return;
    if (current() == '(') {
        consume('(');
        parse_L();
        if (!error) consume(')');
    } else if (current() == 'a') {
        consume('a');
    } else {
        error = 1;
    }
}

// L -> S L'
void parse_L() {
    if (error) return;
    parse_S();
    parse_Lprime();
}

// L' -> , S L' | epsilon
void parse_Lprime() {
    if (error) return;
    if (current() == ',') {
        consume(',');
        parse_S();
        parse_Lprime();
    }
    // else epsilon - do nothing
}

int main() {
    char buf[1000];
    printf("Enter string: ");
    if (fgets(buf, sizeof(buf), stdin) == NULL) {
        printf("Invalid string\n");
        return 0;
    }
    // Remove newline
    int len = strlen(buf);
    if (len > 0 && buf[len-1] == '\n') buf[--len] = '\0';

    // Remove spaces
    char cleaned[1000];
    int ci = 0;
    for (int i = 0; i < len; i++) {
        if (buf[i] != ' ') cleaned[ci++] = buf[i];
    }
    cleaned[ci] = '\0';

    input = cleaned;
    pos = 0;
    error = 0;

    parse_S();

    if (!error && input[pos] == '\0') {
        printf("Valid string\n");
    } else {
        printf("Invalid string\n");
    }

    return 0;
}
```

## How the Parser Works

Each grammar rule maps directly to a C function:

- **`parse_S()`** — checks if current token is `(` (triggers list rule) or `a` (terminal). Any other character sets `error = 1`.
- **`parse_L()`** — calls `parse_S()` then `parse_Lprime()`.
- **`parse_Lprime()`** — if current token is `,`, consumes it and recurses. Otherwise does nothing (epsilon production).

After parsing, validity is confirmed only if **both** `error == 0` **and** the entire input has been consumed (`pos` is at end of string). This catches cases like `a)` where parsing succeeds partially but leftover characters remain.

---

## Key Concepts

**Recursive Descent Parsing** is a top-down parsing technique where each non-terminal in the grammar is implemented as a recursive function. It works well for LL(1) grammars — grammars where you can always decide which production to apply by looking at just one token ahead (the *lookahead*).

The grammar in this practical is left-factored (L' handles the repeating comma-separated part), making it suitable for RDP without backtracking.
