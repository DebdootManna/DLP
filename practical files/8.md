# Practical 8 — Predictive Parsing Table Construction and LL(1) Grammar Validation

## Objective

Construct a predictive (LL(1)) parsing table for a given grammar, determine whether the grammar is LL(1), and — if it is — validate input strings against it using a non-recursive predictive parser.

---

## Grammar

The grammar recognises sequences of terminals `a`, `b`, `c` and parenthesised sub-expressions:

```
S  →  T S'
S' →  T S'  |  ε
T  →  ( S )  |  a  |  b  |  c
```

| Non-terminal | Meaning |
|---|---|
| `S` | A non-empty sequence of tokens |
| `S'` | Optional continuation of the sequence |
| `T` | A single token or a parenthesised group |

---

## FIRST and FOLLOW Sets

### FIRST

| Symbol | FIRST |
|---|---|
| `T` | `{ (, a, b, c }` |
| `S` | `{ (, a, b, c }` |
| `S'` | `{ (, a, b, c, ε }` |

**Rules used:**

1. For `T → ( S )`: `(` ∈ FIRST(T).  
2. For `T → a`, `T → b`, `T → c`: each terminal belongs to its own FIRST.  
3. For `S → T S'`: FIRST(S) = FIRST(T) (T has no ε).  
4. For `S' → T S'`: FIRST(T) ⊆ FIRST(S').  
5. For `S' → ε`: ε ∈ FIRST(S').  

### FOLLOW

| Symbol | FOLLOW |
|---|---|
| `S` | `{ $, ) }` |
| `S'` | `{ $, ) }` |
| `T` | `{ (, a, b, c, $, ) }` |

**Rules used:**

1. `$` ∈ FOLLOW(S) because S is the start symbol.  
2. In `T → ( S )`: `)` ∈ FOLLOW(S).  
3. In `S → T S'`: FOLLOW(S) ⊆ FOLLOW(S') because S' can derive ε.  
4. In `S' → T S'` and `S → T S'`: FIRST(S') \ {ε} ⊆ FOLLOW(T); since S' can derive ε, FOLLOW(S) and FOLLOW(S') ⊆ FOLLOW(T).  

---

## Predictive Parsing Table

The table is constructed by applying:

- **Rule 1**: For each production `A → α`, for each terminal `a ∈ FIRST(α)`, add `A → α` to `M[A, a]`.  
- **Rule 2**: If `ε ∈ FIRST(α)`, for each `b ∈ FOLLOW(A)`, add `A → α` to `M[A, b]`.

| | `(` | `)` | `a` | `b` | `c` | `$` |
|---|---|---|---|---|---|---|
| **S** | `S → T S'` | — | `S → T S'` | `S → T S'` | `S → T S'` | — |
| **S'** | `S' → T S'` | `S' → ε` | `S' → T S'` | `S' → T S'` | `S' → T S'` | `S' → ε` |
| **T** | `T → ( S )` | — | `T → a` | `T → b` | `T → c` | — |

No cell contains more than one production → **the grammar is LL(1)**.

---

## LL(1) Check

A grammar is LL(1) if and only if, for every non-terminal `A` and every pair of distinct productions `A → α` and `A → β`:

1. FIRST(α) ∩ FIRST(β) = ∅  
2. At most one of α, β can derive ε  
3. If α ⟹\* ε then FIRST(β) ∩ FOLLOW(A) = ∅

All three conditions are satisfied here, confirming the grammar is **LL(1)**.

---

## Parsing Algorithm

Uses a stack-based non-recursive predictive parser:

```
push $
push S
a = next_token()
repeat:
  X = top of stack
  if X == a == $:        ACCEPT
  if X is terminal:      if X == a: pop, advance a  else ERROR
  if X is non-terminal:  if M[X,a] = X → Y1..Yk: pop X, push Yk..Y1
                         else ERROR
```

> `()` is invalid because `T → ( S )` requires S to match at least one token — S derives `T S'`, and T has no ε production, so an empty body is rejected.

## Key Concepts Summary

| Concept | Description |
|---|---|
| **FIRST(α)** | Set of terminals that can begin strings derived from α |
| **FOLLOW(A)** | Set of terminals that can appear immediately after A in any sentential form |
| **LL(1) table** | Maps (non-terminal, lookahead) → production; LL(1) iff no cell has > 1 entry |
| **Predictive parser** | Stack-driven, uses one lookahead token, no backtracking |
