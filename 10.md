# Practical 10 – Evaluating Arithmetic Expressions with Bottom-Up Approach Using SDD

## Objective

Develop a program to evaluate arithmetic expressions containing operators using a bottom-up parsing approach and Syntax-Directed Definitions (SDD) for semantic evaluation. The program builds a parse tree and incorporates semantic rules to evaluate sub-expressions during parsing.

---

## Grammar & SDD Rules

| Production | Semantic Rule |
|---|---|
| L → E n | Print(E.val) |
| E → E + T | E.Val = E.val + T.val |
| E → E - T | E.Val = E.val - T.val |
| E → T | E.val = T.val |
| T → T * F | T.val = T.val * F.val |
| T → T / F | T.val = T.val / F.val |
| T → F | T.val = F.val |
| F → G ^ F | F.val = G.val ^ F.val |
| F → G | F.val = G.val |
| G → ( E ) | G.val = E.val |
| G → digit | G.val = digit.lexval |

---

## Approach: Recursive Descent Parser (Bottom-Up Semantics)

The parser is implemented as a **recursive descent parser** with each non-terminal (`E`, `T`, `F`, `G`) corresponding to a function. Operator precedence and associativity are encoded directly in the grammar:

| Precedence | Operator | Associativity | Non-terminal |
|---|---|---|---|
| Lowest | `+`, `-` | Left | `E` |
| Medium | `*`, `/` | Left | `T` |
| High | `^` | **Right** | `F` |
| Highest | `()`, numbers | — | `G` |

> **Key design decision:** Exponentiation (`^`) is right-associative. `3^2^3` is parsed as `3^(2^3) = 3^8 = 6561`, implemented by making `parseF()` recursively call itself on the right operand.

## Source Code – `10.cpp`

```cpp
#include <iostream>
#include <string>
#include <stdexcept>
#include <cmath>
#include <cctype>

class Parser {
    std::string input;
    size_t pos;

    void skipSpaces() {
        while (pos < input.size() && input[pos] == ' ')
            pos++;
    }

    // G -> ( E ) | number
    double parseG() {
        skipSpaces();
        if (pos >= input.size())
            throw std::runtime_error("Invalid expression");

        if (input[pos] == '(') {
            pos++;
            double val = parseE();
            skipSpaces();
            if (pos >= input.size() || input[pos] != ')')
                throw std::runtime_error("Invalid expression");
            pos++;
            return val;
        }

        if (isdigit(input[pos]) || input[pos] == '.') {
            size_t start = pos;
            while (pos < input.size() && (isdigit(input[pos]) || input[pos] == '.'))
                pos++;
            return std::stod(input.substr(start, pos - start));
        }

        throw std::runtime_error("Invalid expression");
    }

    // F -> G ^ F | G  (right-associative)
    double parseF() {
        double base = parseG();
        skipSpaces();
        if (pos < input.size() && input[pos] == '^') {
            pos++;
            double exp = parseF();  // right-recursive
            return std::pow(base, exp);
        }
        return base;
    }

    // T -> T * F | T / F | F  (left-associative)
    double parseT() {
        double val = parseF();
        skipSpaces();
        while (pos < input.size() && (input[pos] == '*' || input[pos] == '/')) {
            char op = input[pos++];
            double right = parseF();
            if (op == '*') val *= right;
            else {
                if (right == 0) throw std::runtime_error("Invalid expression");
                val /= right;
            }
            skipSpaces();
        }
        return val;
    }

    // E -> E + T | E - T | T  (left-associative)
    double parseE() {
        double val = parseT();
        skipSpaces();
        while (pos < input.size() && (input[pos] == '+' || input[pos] == '-')) {
            char op = input[pos++];
            double right = parseT();
            if (op == '+') val += right;
            else           val -= right;
            skipSpaces();
        }
        return val;
    }

public:
    double evaluate(const std::string& expr) {
        input = expr;
        pos = 0;
        double result = parseE();
        skipSpaces();
        if (pos != input.size())
            throw std::runtime_error("Invalid expression");
        return result;
    }
};

int main() {
    std::string expr;
    std::cout << "Enter arithmetic expression: ";
    std::getline(std::cin, expr);

    Parser parser;
    try {
        double result = parser.evaluate(expr);
        if (result == (long long)result)
            std::cout << (long long)result << std::endl;
        else
            std::cout << result << std::endl;
    } catch (const std::exception&) {
        std::cout << "Invalid expression" << std::endl;
    }

    return 0;
}
```

## Sample Walkthrough: `(3 + 5) * 2 ^ 3`

```
parseE()
  └── parseT()
        ├── parseF()
        │     └── parseG()  →  "(3 + 5)"
        │           └── parseE()
        │                 ├── parseT() → parseF() → parseG() → 3
        │                 └── + parseT() → parseF() → parseG() → 5
        │                 = 8
        └── * parseF()
              ├── parseG() → 2
              └── ^ parseF()
                    └── parseG() → 3
              = 2^3 = 8
  = 8 * 8 = 64
```

## Error Handling

The program throws an exception and prints `"Invalid expression"` for:
- Missing operands (e.g., `3 + ^ 5`)
- Unmatched parentheses (e.g., `(3 + 5 * 2`)
- Trailing invalid characters
- Division by zero
