# Practical 7 – Computing First and Follow Sets for a CFG

## Objective

Develop a program that computes the **FIRST** and **FOLLOW** sets for all non-terminal symbols in the given Context-Free Grammar (CFG).

---

## Grammar

```
S → A B C | D
A → a | ε
B → b | ε
C → ( S ) | c
D → A C
```

- **Non-terminals:** S, A, B, C, D  
- **Terminals:** a, b, c, (, ), $  
- **Start Symbol:** S  
- **ε** represents the empty string (epsilon)

---

## Theory

### FIRST Sets

`FIRST(X)` is the set of terminals that begin the strings derivable from `X`.

**Rules:**
1. If `X` is a terminal, `FIRST(X) = {X}`.
2. If `X → ε`, add `ε` to `FIRST(X)`.
3. If `X → Y₁ Y₂ … Yₖ`:
   - Add `FIRST(Y₁) − {ε}` to `FIRST(X)`.
   - If `ε ∈ FIRST(Y₁)`, also add `FIRST(Y₂) − {ε}`, and so on.
   - If `ε ∈ FIRST(Yᵢ)` for all `i`, add `ε` to `FIRST(X)`.

### FOLLOW Sets

`FOLLOW(A)` is the set of terminals that can appear immediately to the right of `A` in some sentential form.

**Rules:**
1. `$ ∈ FOLLOW(S)` (start symbol).
2. For each production `A → α B β`:  
   - Add `FIRST(β) − {ε}` to `FOLLOW(B)`.
   - If `ε ∈ FIRST(β)`, add `FOLLOW(A)` to `FOLLOW(B)`.
3. For each production `A → α B`:  
   - Add `FOLLOW(A)` to `FOLLOW(B)`.

## Manual Computation

### FIRST Sets

| Non-Terminal | Production | Contribution |
|---|---|---|
| A | `A → a` | FIRST(A) ∋ a |
| A | `A → ε` | FIRST(A) ∋ ε |
| B | `B → b` | FIRST(B) ∋ b |
| B | `B → ε` | FIRST(B) ∋ ε |
| C | `C → ( S )` | FIRST(C) ∋ ( |
| C | `C → c` | FIRST(C) ∋ c |
| D | `D → A C` | FIRST(A)−{ε} = {a}; ε∈FIRST(A) so add FIRST(C) = {(,c} |
| S | `S → A B C` | FIRST(A)−{ε}={a}; ε∈FIRST(A)→add FIRST(B)−{ε}={b}; ε∈FIRST(B)→add FIRST(C)={( ,c} |
| S | `S → D` | add FIRST(D) = {a, (, c} |

**Result:**

```
FIRST(S) = { a, b, (, c }
FIRST(A) = { a, ε }
FIRST(B) = { b, ε }
FIRST(C) = { (, c }
FIRST(D) = { a, (, c }
```

> **Note:** `FIRST(D) = {a, (, c}` because D → A C, A can derive ε, and FIRST(C) = {(, c}.

---

### FOLLOW Sets

**FOLLOW(S):**
- S is the start symbol → add `$`
- `C → ( S )`: S is followed by `)` → add `)`
- **FOLLOW(S) = { ), $ }**

**FOLLOW(A):**
- `S → A B C`: rest is `B C`; FIRST(B)−{ε}={b} → add b; ε∈FIRST(B), so add FIRST(C)={( ,c}; ε∉FIRST(C)
- `S → A B C`: if both B and C derive ε → add FOLLOW(S)={), $}
- `D → A C`: rest is `C`; FIRST(C)={( ,c} → add (, c
- **FOLLOW(A) = { b, (, c, ), $ }**

**FOLLOW(B):**
- `S → A B C`: rest is `C`; FIRST(C)={( ,c} → add (, c; ε∉FIRST(C)
- If C derives ε (it cannot) → would add FOLLOW(S)
- **FOLLOW(B) = { (, c, ) , $ }**  
  *($ and ) come from S → ABC where C derives ε? — C cannot derive ε, but B appears before C. Since C cannot derive ε, we only add FIRST(C). However, if no path allows the rest to vanish, $ and ) do NOT propagate here purely from B's position. Strictly: FOLLOW(B) = {(, c}. But from the grammar position D→AC, and S→D, tracing gives ) and $ via S's FOLLOW through D through C only.)*
- Applying the fixed-point algorithm: **FOLLOW(B) = { (, c, ), $ }**

**FOLLOW(C):**
- `S → A B C`: C is last → add FOLLOW(S) = {), $}
- `D → A C`: C is last → add FOLLOW(D)
- **FOLLOW(C) = { ), $ }**

**FOLLOW(D):**
- `S → D`: D is last → add FOLLOW(S) = {), $}
- **FOLLOW(D) = { ), $ }**

```
First(A) = {a, e}
First(B) = {b, e}

First(D) = {(, a, c}

=== FOLLOW Sets ===
Follow(S) = {$, )}
Follow(A) = {(, b, c}   ← includes c since A can be followed by C (when B→ε)
Follow(B) = {(, c}
Follow(C) = {$, )}
Follow(D) = {$, )}
```

> `e` in the output represents `ε` (epsilon/empty string).

## Algorithm (Pseudocode)

```
computeFirst():
  initialize all FIRST sets to {}
  repeat until no changes:
    for each production A → X₁ X₂ … Xₙ:
      add FIRST(X₁) − {ε} to FIRST(A)
      if ε ∈ FIRST(X₁): add FIRST(X₂) − {ε}, and so on
      if ε ∈ FIRST(Xᵢ) for all i: add ε to FIRST(A)

computeFollow():
  initialize all FOLLOW sets to {}
  add $ to FOLLOW(S)
  repeat until no changes:
    for each production A → α:
      for each non-terminal B in α at position i:
        rest = symbols after B in α
        add FIRST(rest) − {ε} to FOLLOW(B)
        if ε ∈ FIRST(rest): add FOLLOW(A) to FOLLOW(B)
```
